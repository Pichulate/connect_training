# Busca de Empresas e Mentores

## Visão Geral

O módulo de busca permite localizar rapidamente **empresas do portfólio** e **mentores** cadastrados no Endeavor Connect. É o ponto de entrada para qualquer interação no sistema — antes de criar um meeting ou uma priority, você precisa localizar a empresa e/ou o mentor envolvido.

---

## Busca de Empresas

### Como acessar
Acesse a seção **Empresas** no menu principal ou use a barra de busca global.

### O que você pode buscar
- Nome da empresa
- Setor / vertical de atuação
- Estágio da empresa
- Localização
- Empreendedor(a) responsável

### Informações disponíveis no perfil da empresa

| Campo | Descrição |
|---|---|
| **Nome** | Razão social ou nome fantasia da empresa |
| **Estágio** | Fase atual da empresa (ex: Seed, Series A, Scale-up) |
| **Setor** | Vertical de atuação (ex: Healthtech, Fintech, Agro) |
| **Empreendedores** | Fundadores e líderes cadastrados |
| **Histórico de meetings** | Todas as mentorias já registradas |
| **Priorities ativas** | Desafios em aberto da empresa |
| **Programa** | Programa Endeavor ao qual a empresa está vinculada |

### Boas práticas
- Sempre confirme se a empresa já está cadastrada antes de criar um novo registro
- Verifique se os dados da empresa estão atualizados (especialmente estágio e empreendedores)
- Use filtros para narrowing down quando o portfólio for extenso

## Busca de Mentores

### Como acessar
Acesse a seção **Mentores** no menu principal ou use a barra de busca global.

### O que você pode buscar
- Nome do mentor
- Área de expertise
- Setor de atuação
- Disponibilidade
- Histórico de mentorias com a Endeavor

### Informações disponíveis no perfil do mentor

| Campo | Descrição |
|---|---|
| **Nome** | Nome completo do mentor |
| **Empresa / Cargo** | Organização atual e posição |
| **Áreas de expertise** | Tags de especialização (ex: Go-to-Market, Finanças, RH) |
| **Setores de atuação** | Indústrias em que tem experiência |
| **Disponibilidade** | Horários ou períodos disponíveis para mentoria |
| **Histórico de meetings** | Mentorias já realizadas com empresas Endeavor |
| **Rating** | Avaliação média das mentorias realizadas |

### Boas práticas
- Ao buscar mentores para uma priority, use as tags de expertise como filtro principal
- Verifique o histórico de meetings do mentor com a empresa antes de sugerir — evita repetição sem valor agregado
- Confirme a disponibilidade antes de marcar um meeting como Scheduled
- Mentores com alto rating e histórico ativo têm maior taxa de resposta

---

## Dicas de busca

- A busca é **case-insensitive** — não se preocupe com maiúsculas/minúsculas
- Use **termos parciais** quando não souber o nome exato
- Os filtros são **cumulativos** — você pode combinar setor + estágio + programa simultaneamente
- O sistema de recomendação automática de mentores (via Priorities) usa os mesmos critérios de busca de forma inteligente — ver `priorities.md`
